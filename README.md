# Sudarson Balakrishnan — AI & Data Science Engineer Portfolio

A premium, cyber-aesthetic engineering portfolio built with **Next.js 15**, **Three.js / React Three Fiber**, **Tailwind CSS**, and **TypeScript**.

🌐 **Live Demo**: [sudarson-balakrishnan-portfolio.vercel.app](https://sudarson-balakrishnan-portfolio.vercel.app/)

---

## ✨ Features

- **Dynamic Interactive Target Cursor**: Custom square scope reticle with smooth easing, cardinal crosshairs, rotating brackets, and interactive target locks.
- **Cinematic 3D Scenes**: Procedural 3D topographic contours, flowing silk ribbons, and interactive network topology graphics powered by Three.js.
- **Rotating Editorial Role Typography**: Precision sequenced role text reveals.
- **Categorized Tech Ecosystem**: Detailed mapping of AI, Data Engineering, Full-Stack, Cloud & DevOps competencies.
- **Live Project Showcase**: Comprehensive architecture breakdowns, metrics, live production links, and GitHub repositories.
- **Automated Transmission Pipeline**: Integrated contact dispatch routing payloads directly to `sudarsonbalu@gmail.com`.
- **Dynamic Theme Engine**: Global theme color customizer with instant accent shifts.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **3D & Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Styling**: Tailwind CSS
- **Animations**: GSAP, Framer Motion, Lenis Smooth Scroll
- **Icons**: Lucide React
- **Language**: TypeScript

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Sudarsonbalu/Sudarsonbalakrishnan_portfolio.git

# Navigate to project directory
cd Sudarsonbalakrishnan_portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
